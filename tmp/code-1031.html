오늘 아침 이 블로그 공개 글 24편의 대표 그림 주소를 한 번에 뽑아 봤더니 4편이 티스토리 기본 그림으로 나가고 있었습니다. 티스토리 대표이미지 설정은 본문에 그림을 넣는다고 끝나지 않아요. 자동으로 올린 글이라면 발행 창에서 대표 칸에 파일을 따로 올려야 잡힙니다.

오늘 확인한 것

  • 2026-10-31 기준 이 블로그 24편 중 20편은 대표 그림이 blog.kakaocdn.net, 4편(9월 22~23일 글)은 opengraph.png 기본 그림
  • 본문에 바깥 주소(jsDelivr) 그림만 넣으면 티스토리가 대표로 못 잡음
  • '완료' 뒤 발행 창의 대표이미지 칸에 jpg를 올리면 kakaocdn 주소로 바뀜
  • 이 계정 썸네일은 1200×1200 한 장, 큰 글자는 세로 330~870px 사이

내 글이 기본 그림인지, 명령 한 줄이면 압니다

눈으로 다음 검색 결과를 넘겨 보는 것보다 빠른 길이 있어요. 맥 터미널이나 윈도 파워쉘에 아래를 붙이고 주소만 바꾸면 됩니다.

curl -s 글주소 | grep -o 'og:image" content="[^"]*'

결과가 blog.kakaocdn.net 이 들어간 주소면 정상이고, opengraph.png 나 tistory_admin 이 보이면 기본 그림입니다. og:image(공유될 때 보여 줄 그림을 적어 두는 칸)는 다음 검색 썸네일과 카톡 공유 카드가 같이 읽는 자리라, 여기가 비면 둘 다 빈 그림이 돼요.

고치는 순서 — 발행 창에서 한 번 더

편집기에서 완료를 누르면 공개 설정 창이 뜨고, 그 위쪽에 대표이미지 칸이 있습니다. 여기에 jpg를 올린 뒤 작은 미리보기 그림이 생겼는지 보고, 그다음에 공개를 고르고 발행합니다. 이 계정 예약 작업은 미리보기가 안 생기면 발행 자체를 멈춰요.

클로드에게 맡긴다면 아래 단락을 발행 지시서에 그대로 붙이세요. 대괄호 두 곳만 바꾸면 됩니다.

티스토리에 글을 올릴 때 본문에 넣은 그림은 대표이미지로 치지 마. '완료'를 눌러 발행 창이 뜨면 대표이미지 칸에 [대표로 쓸 jpg 파일 경로]를 올리고, 미리보기 그림이 생긴 걸 확인한 뒤에만 '공개 발행'을 눌러. 미리보기가 5초 안에 안 생기면 발행하지 말고 멈춰서 알려 줘. 발행이 끝나면 공개 주소를 열어 og:image 값이 blog.kakaocdn.net 으로 시작하는지 확인하고, opengraph.png 면 실패로 [보고 받을 곳]에 한 줄 남겨.

이 단락은 대표 그림 하나만 지킵니다. 같은 식으로 글을 올리기 직전에 컴퓨터가 막아 주는 자동 검사 20가지, 한 달 매일 돌리며 실제로 겪은 실수 11가지는 제가 만든 책에 따로 묶어 두었어요. 10월 31일 상품 페이지 기준 9,900원입니다.

티스토리 대표이미지 안됨, 본문 그림이 바깥 주소일 때

이 계정은 그림을 깃허브 저장소에 올리고 jsDelivr 주소로 본문에 넣습니다. 무료 이미지 호스팅에 올렸던 그림 7장이 만료되거나 사라진 뒤로 바꾼 방식이에요. 문제는 티스토리가 이런 바깥 주소 그림을 대표로 쓰지 않는다는 점이었습니다. 10월 5일 메인 블로그를 점검하다 9월 이후 자동 발행 글이 전부 기본 그림이었다는 걸 알았고, 코드 블로그의 9월 글 4편이 그때 고치지 못하고 남은 것들이에요.

손으로 글을 쓸 때는 편집기에 사진을 끌어다 놓으니 티스토리 서버에 올라가서 저절로 대표가 됩니다. 클로드가 본문 HTML을 통째로 넣는 자동 발행에서만 생기는 빈틈이에요.

티스토리 썸네일 크기, 한 장이 두 번 잘려요

티스토리 도움말에서 권장 크기를 숫자로 적어 둔 곳은 찾지 못했습니다. 이 계정은 1200×1200 정사각 한 장으로 씁니다. 다음 검색 목록은 네모 칸에 통째로 보여 주지만 카톡 공유 카드는 가운데 가로 띠만 남기거든요. 그래서 썸네일 도구가 큰 글자를 세로 330~870px 사이에만 놓습니다.

블로그 썸네일 만들기를 자동으로 돌린다면 그림 안 글자는 질문 한 줄과 숫자 하나면 충분해요. 표나 흐름도를 대표로 쓰면 목록에서 글자가 너무 작아집니다.

이미 올린 글이 기본 그림이라면

글을 다시 써야 하나요?

아니요. 글 관리에서 수정을 열고 완료를 누르면 같은 발행 창이 뜨니, 대표이미지 칸에 올리고 다시 발행하면 됩니다. 이 계정에서 옛 글을 이렇게 고쳤을 때 발행 날짜는 바뀌지 않았어요.

본문 첫 그림을 티스토리에 직접 올리면 되지 않나요?

그것도 방법입니다. 다만 대표 칸을 따로 지정해 두면 본문 그림 순서가 바뀌어도 대표가 흔들리지 않아요.

바꿨는데 카톡 카드는 그대로예요

카톡은 한 번 읽은 공유 카드를 한동안 기억합니다. 공개 주소의 og:image가 kakaocdn으로 바뀌었는지부터 위 명령으로 확인하세요.

대표 그림은 제대로인데 검색 유입 자체가 0이라 걱정이라면, 티스토리 저품질 확인 글에서 이 계정이 실제로 본 순서를 따라가 보세요.

지금 할 일 하나만 고르면, 가장 최근 글 주소로 위 curl 한 줄을 돌려 보는 겁니다.
