"클로드로 홈페이지 만들면 결국 돈이 얼마나 들어요?" 클로드 홈페이지 제작방법을 찾는 분이 제일 먼저 묻는 말인데요. 소개 페이지·성적표 같은 한 장짜리라면 올려 두는 비용은 0원입니다. 클로드 코드가 파일을 만들고, GitHub Pages(깃허브가 공개 저장소를 무료로 웹페이지로 띄워 주는 기능)에 올리면 끝이에요.

먼저 숫자만

  • GitHub Pages는 무료 계정이면 공개 저장소에서 0원으로 쓴다(GitHub 문서, 2026-11-10 확인)
  • 사이트 크기는 1GB까지, 방문 데이터는 한 달 100GB가 권장 한도다
  • 쇼핑몰·결제·비밀번호를 받는 페이지는 이 무료 호스팅에 올리면 안 된다
  • 이 블로그 성적표 페이지는 10월 13일부터 4주 동안 709번 고쳐 올렸고 호스팅비는 0원이었다

여기서 덮으면 한 가지를 놓칩니다. 무료로 올릴 수 있는 페이지와 올리면 안 되는 페이지가 GitHub 규칙에 따로 적혀 있거든요. 가게 홈페이지를 생각 중이라면 아래 '여기엔 올리지 마세요' 칸부터 보세요.

클로드 홈페이지 배포 방법, 이 순서로 따라가세요

클로드 홈페이지 배포 방법에서 사람들이 제일 많이 헷갈리는 건 "클로드랑 클로드 코드가 같은 거냐"는 부분입니다. 채팅창 클로드도 HTML(웹페이지 글자 파일)을 써 주지만, 그걸 파일로 저장하고 저장소에 올리는 일까지 하는 건 클로드 코드예요. 그래서 순서는 이렇습니다.

① GitHub에 가입해 공개 저장소 하나를 만든다 → ② 그 폴더에서 클로드 코드를 열고 아래 단락을 붙여 넣는다 → ③ 저장소 Settings → Pages에서 Branch를 main, 폴더를 / (root)로 두고 저장한다 → ④ 몇 분 뒤 '아이디.github.io/저장소이름' 주소로 열어 본다.

"이 폴더에 index.html 한 장짜리 소개 페이지를 만들어 줘. 휴대폰에서 먼저 보기 좋게, 외부 파일 없이 한 파일 안에 글꼴·색을 다 넣어. 내 이름·하는 일·연락 방법 세 칸만 두고, 연락처 칸은 비워 둔 채 나에게 물어봐. 비밀번호·카드번호·개인 메모는 이 폴더에 절대 쓰지 마. 다 만들면 브라우저로 열어 휴대폰 너비에서 가로로 밀리는 곳이 없는지 확인한 뒤 커밋하고 푸시해."

마지막 줄이 핵심이에요. 저희 성적표 페이지는 수집 스크립트가 숫자를 모으면 같은 순서로 파일을 다시 쓰고 git push(바뀐 파일을 저장소로 올리는 명령)를 합니다. 사람이 손대는 건 없고, 그렇게 4주 동안 709번이 올라갔어요.

여기까지가 한 장짜리 페이지입니다. 매일 숫자를 모아 고쳐 올리게 하려면 예약 작업에 넣을 지시서와, 어제 한 일을 AI가 기억하게 하는 메모 파일이 따로 필요해요. 저는 그 지시서 전체와 바로 복사해 쓰는 템플릿 7개를 29쪽 PDF로 묶어 래피드에 올려 뒀습니다. 제가 만든 책이에요(오늘 상품 페이지 기준 3,900원, 첫 3쪽 미리보기 있음).

여기엔 올리지 마세요

GitHub 문서는 GitHub Pages를 온라인 장사·쇼핑몰·상업 거래용 무료 호스팅으로 쓰는 걸 허용하지 않는다고 적어 둡니다. 비밀번호나 카드번호를 주고받는 페이지도 안 되고요. 그러니 주문·결제가 붙는 가게 홈페이지라면 처음부터 빌더나 유료 호스팅으로 가는 게 맞습니다.

하나 더, 무료로 쓰는 건 공개 저장소라서 파일이 누구에게나 보입니다. 저희 성적표 페이지도 그래서 검색엔진에 안 뜨게 noindex(검색에 올리지 말라는 표시)를 붙이고, 열쇠 값은 저장소 밖에 둡니다. 자동화에 비밀번호를 안 넘기는 선은 클로드 개인정보 보호방법 글에 따로 정리했어요.

클로드 홈페이지 제작 요금제, 따로 올려야 하나

클로드 홈페이지 제작 요금제를 따로 고를 필요는 없습니다. 한 장짜리 페이지는 지시 한 번에 끝나서 쓰던 요금제 안에서 충분해요. 다만 매일 자동으로 고치게 돌리면 사용량이 쌓이니, 그때는 자동화용 요금제 비교 글을 보고 고르시면 됩니다.

클로드 홈페이지 제작방법, 시작 전에 걸리는 물음

클로드 채팅창만으로도 홈페이지를 올릴 수 있나요?

페이지 글은 받을 수 있지만 저장소에 올리는 건 직접 해야 합니다. 파일 저장부터 푸시까지 맡기려면 클로드 코드를 씁니다.

GitHub Pages는 정말 계속 무료인가요?

무료 계정은 공개 저장소에서 쓸 수 있습니다. 사이트 1GB, 한 달 100GB 권장 한도를 넘으면 GitHub가 다른 방법을 권하는 메일을 보낼 수 있어요.

내 도메인을 붙이면 돈이 드나요?

GitHub Pages 쪽은 그대로 0원이고, 도메인은 산 곳에 해마다 따로 냅니다. 주소가 아이디.github.io여도 괜찮다면 0원으로 끝납니다.
